# Cybersecurity Virtual Lab Setup

## Overview
Week 1 project for the Network Walks Cybersecurity Internship Program (Batch B084).

This project documents setting up a virtual lab using Oracle VirtualBox and Kali Linux.

## Objectives
- Install and configure Oracle VirtualBox.
- Import and configure Kali Linux.
- Create a private NAT Network.
- Configure and verify network settings.
- Understand NAT versus NAT Network.
